# 🎮 CFGG Website: Project Story

## 🧠 Project Concept

The CFGG website is a multi-page site designed to showcase and promote a curated range of gaming consoles — including Nintendo Switch, PlayStation, and mobile devices. This project was developed as part of the *Introduction to Web Development* course by Code First Girls (CFG) and represents a hands-on application of front-end web development principles.

The website consists of multiple HTML pages styled with CSS and includes plans for improved responsiveness, accessibility, and future interactivity. This version of the project has been fully reorganized and upgraded using modern best practices.

---

## 🛠 Development Environment

While many CFG participants use VS Code, this project was built using **PyCharm Community Edition**, offering powerful code navigation, project structure control, and versioning support.

Version control was handled via Git and GitHub for collaboration and deployment preparation.

---

## 📅 Project Timeline

- **Week 1–2:** Learned HTML and built initial structure and pages
- **Week 3:** Applied CSS styling, layout grids, and component styling
- **Week 4:** Created additional product pages, added navigation and structure
- **Week 5+:** Restructured files, enhanced responsiveness, and prepared GitHub repo

---

## 🎓 Alignment with CFG Course Curriculum

This project reflects all major areas taught in the CFG *Introduction to Web Development* course:

- ✅ HTML5 page structure and semantic tags
- ✅ External CSS styling using a centralized stylesheet
- ✅ Bootstrap used for layout responsiveness and visual consistency
- ✅ UX design principles applied to layout, navigation, and readability
- ✅ Git & GitHub for version control and remote collaboration
- ⚠️ Accessibility (alt text, color contrast, keyboard navigation) partially implemented
- ⚠️ JavaScript used minimally (future improvements planned)
- 🚀 Preparing for deployment on GitHub Pages

---

## 🎯 Learning Objectives

- Structure multi-page websites using semantic HTML
- Apply consistent styles using external CSS
- Implement responsive layout concepts with Bootstrap
- Build user-friendly navigation and content layout
- Use Git and GitHub to manage and document project progress
